🌐 GitHub Pages 업로드 가이드

1단계. github.com 회원가입 (무료)
2단계. 'New repository' 버튼 클릭 → 이름 입력 (예: order-dashboard)
3단계. 이 HTML 파일을 index.html로 이름 바꿔 업로드
4단계. Settings → Pages → Source: main / root 선택 → Save
5단계. https://[아이디].github.io/order-dashboard URL을 팀에 공유

업데이트 방법: HTML 파일을 다시 업로드하면 URL은 그대로 유지돼요.
⚠️ 이 파일에는 로그인 정보가 포함되어 있으므로 Private repository로 설정하세요 (Settings → General → Change visibility)
